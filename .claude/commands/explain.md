# Explain Vulnerability

Explain a security vulnerability type in simple terms.

Usage: /explain [vulnerability-type]

Examples:
- /explain sql-injection
- /explain xss
- /explain hardcoded-secrets

Use the Guardian-Agent `explain_vulnerability` tool to get:
- Simple explanation
- How the attack works
- Example attack
- Impact
- How to fix it

If no type specified, list available vulnerability types.
